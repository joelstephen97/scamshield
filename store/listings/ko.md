## Name

사기 및 피싱 차단기: ScamShield

## Short description

사기 사이트, 피싱 페이지, 가짜 쇼핑몰을 차단합니다. 100% 기기 내 처리로, 인터넷 사용 기록은 컴퓨터 밖으로 나가지 않습니다.

## Full description

ScamShield는 사기 사이트나 피싱 페이지에 속기 전에 미리 경고해 드리며, 모든 확인 작업은 브라우저 안에서 이루어집니다. 서버는 존재하지 않습니다. 방문하거나 입력하거나 붙여넣은 내용은 절대 어디로도 전송되지 않습니다.

왜 ScamShield인가

대부분의 사기 차단 프로그램은 방문한 페이지를 회사 서버로 보내고 판정을 기다립니다. ScamShield는 같은 방식의 탐지를 사용자의 기기에서 직접 실행합니다. 그래서 계정이 필요 없고, 서버 장애로 보호받지 못하는 일도 없으며, 나중에 유출되거나 판매될 수 있는 인터넷 사용 기록도 남지 않습니다.

완전히 무료이며, 프리미엄 등급도 체험판도 "실시간 보호를 잠금 해제하려면 업그레이드하세요" 같은 안내도 없습니다. 제품 전체가 곧 무료 제품입니다.

차단하는 항목

• 가짜 은행 및 브랜드 로그인. ScamShield는 페이지의 아이콘과 로고를 64개 유명 브랜드(PayPal, Microsoft, Google을 비롯해 지역 은행, 통신사, 정부 서비스 포함) 목록과 비교하고, 브랜드 이름을 비슷한 외국 문자로 흉내 낸 유사 도메인도 찾아냅니다. 올바른 로고를 엉뚱한 도메인에 사용한 가짜 로그인은 주소가 낯설어 보이지 않아도 탐지됩니다.

• 가짜 쇼핑몰. 가짜 카운트다운 타이머, "재고 2개 남음" 같은 압박 문구, 그대로 베낀 신뢰 배지, 플랫폼 밖에서 결제하라는 요구, 빠진 연락처 정보를 결제 전 쇼핑 카드에서 보여 드립니다.

• 암호화폐 지갑 탈취. 계정 위임 및 다중 지갑 요청을 포함해 위험한 승인과 블라인드 서명 전에 경고하며, 복구 구문을 훔치려는 시도를 차단합니다.

• 기술 지원 사기. "PC가 감염되었으니 이 번호로 전화하세요" 같은 페이지를 전체 화면으로 차단하고, 페이지의 화면 잠금과 뒤로 가기 버튼 함정을 먼저 무력화하는 원클릭 탈출 기능을 제공합니다.

• ClickFix 및 클립보드 공격. 가짜 "사람인지 확인" 절차로 유도해 Windows 실행 창에 명령어를 붙여넣게 만드는 수법입니다. ScamShield는 악성 클립보드 내용을 바꿔치기하고, 명령어가 실행되기 전에 페이지를 차단합니다.

• 정보가 새는 양식. 입력한 이메일이나 전화번호를 사이트가 트래커로 전송하는 순간, 제출 버튼을 누르기도 전에 경고합니다. 핑거프린팅 스크립트와 "계속하려면 허용을 클릭하세요" 같은 알림 함정도 알려 드립니다.

• 위험한 검색 결과. Google, Bing, DuckDuckGo에서 이미 알려진 악성 도메인이거나 브랜드와 매우 비슷한 검색 결과에 작은 빨간색 또는 호박색 점을 표시해, 클릭하기 전에 위험을 알 수 있습니다.

• QR 코드. 페이지 이미지에 있는 QR 코드를 해석해, 휴대폰으로 스캔하기 전에 어디로 연결되는지 미리 확인합니다.

작동 방식

1. ScamShield는 페이지를 여는 순간 문구, 레이아웃, 로그인 양식, 아이콘을 사용자의 기기에서 읽습니다. 팝업에 붙여넣은 메시지도 읽을 수 있습니다.

2. 기기 내 모델과 여러 규칙이 발견한 내용을 채점합니다. 약한 신호 하나만으로는 조용한 "의심" 표시만 나타납니다. "위험" 판정을 내리려면 여러 독립적인 신호가 함께 확인되어야 하므로, 정상 페이지가 실수로 표시되는 일은 드뭅니다.

3. 빨간 배너만 보여 주는 게 아니라 쉬운 말로 이유를 설명하고, 원클릭 해결 방법도 함께 제공합니다: 위험 경고에는 "이 페이지 나가기", 브랜드 사칭 페이지에는 "진짜 사이트로 이동"이 표시됩니다. ScamShield가 잘못 판단했다면 해당 사이트의 경고를 1시간, 하루, 또는 항상으로 일시 중지할 수 있습니다.

통계 및 설명

모든 경고에는 정확한 이유를 나열하는 "왜 이런 판정인가요?" 패널이 있습니다: 잘못된 도메인에 있는 브랜드 아이콘, 유사 주소, 다른 사이트로 전송되는 비밀번호 입력란 등입니다. 설정의 통계 탭에서는 확인한 페이지 수, 차단한 위협, 개인정보 관련 발견 사항을 최근 7일, 최근 30일, 또는 설치 이후 누적 값으로 나눈 일별 그래프로 보여 줍니다. 모든 수치는 사용자의 기기에서 계산되고 저장됩니다.

개인정보 보호

ScamShield는 방문하는 페이지에 대한 접근 권한을 요청하는데, 이는 기기 내 분석이 페이지를 읽는 방식이기 때문입니다. 확인 작업은 사용자의 브라우저 안에서 로컬로 이루어집니다.

기본 상태에서 기기 밖으로 나가는 유일한 것은 단순한 파일 다운로드입니다: 알려진 사기 도메인의 공개 목록으로, 설치 직후나 오프라인 상태에서도 차단 기능이 작동하도록 ScamShield의 오픈소스 피드에서 내려받습니다. 이 다운로드에는 사용자나 사용자의 인터넷 사용에 관한 어떤 정보도 함께 담기지 않습니다.

기본적으로 꺼져 있는 선택 기능인 커뮤니티 신고를 켜면, 위험으로 표시된 페이지에 대해 익명화된 호스트 이름과 숫자로 된 위험 신호를 전송할 수 있습니다. URL이나 페이지 텍스트, 입력한 내용은 절대 포함되지 않으며, 사용자가 직접 켠 경우에만 작동합니다. 설정 > 정보에서 기기 밖으로 나간 내용을 정확히 확인할 수 있습니다.

자주 묻는 질문

ScamShield는 다른 사기 차단 프로그램이나 AI 사기 검사기와 무엇이 다른가요?

대부분은 방문한 주소, 기기 ID, 챗봇에 붙여넣은 메시지 같은 정보를 자체 서버로 보내 페이지를 확인합니다. ScamShield에는 서버가 없습니다. 페이지 읽기, 브랜드 아이콘 대조, 붙여넣은 메시지 검사, QR 코드 해석까지 모든 작업이 사용자의 기기에서 이루어집니다. 다른 제품들과의 근거 있는 비교는 프로젝트의 GitHub 저장소에 있는 docs/comparison.md 파일에서 확인할 수 있습니다.

ScamShield는 정말 무료인가요? 숨겨진 함정이 있나요?

네, 함정은 없습니다. ScamShield는 요금을 청구할 서버 자체를 운영하지 않으므로 더 팔 것이 없습니다. 여러 경쟁 제품은 제한된 무료 등급만 제공하고 진짜 보호 기능에는 매달 요금을 청구하거나, 유료 보안 제품군으로 유도합니다. ScamShield는 작고 가볍게, 기기 안에서 작동하며, 사용자가 계속 설치해 둘 만큼 충분히 유용하게 유지하는 방식을 택했습니다. 개발을 후원하고 싶다면 확장 프로그램 안에 후원 링크가 있으며, 유료 장벽은 결코 없습니다.

추가로 포함된 기능

• 사기 메시지 검사기: SMS, WhatsApp, 이메일 텍스트를 붙여넣으면 즉시, 완전히 비공개로 판정을 받을 수 있습니다.

• 검색 페이지의 스폰서 결과 확인: 표시된 사이트와 다른 곳으로 연결되는 광고를 표시합니다.

• 엄격 모드: 스위치 하나로 "의심" 단계의 페이지까지 더 쉬운 문구로 전체 화면 차단합니다. 기술에 익숙하지 않은 가족을 위한 기능입니다.

• 언어 선택: 브라우저 언어와 상관없이 팝업이나 설정에서 20개 언어 중 원하는 언어를 고를 수 있습니다.

• 설정 내보내기/가져오기와 브라우저 자체 동기화를 통한 선택적 기기 간 동기화. 이 경우에도 ScamShield 계정이나 서버는 없습니다.

• 다크 모드, 보호 기록, 원클릭 구조 링크, 가짜 경품/사은품 콘텐츠 숨기기.

형용사가 아닌 실제 수치로 말씀드립니다: 메뉴, 경고, 설정까지 완전히 번역된 20개 언어, 약 900개의 자동화된 테스트, 확인된 사기 도메인 425,000개 이상과 100만 개 도메인 감시 목록으로 이루어진 차단 목록(오픈소스 피드에서 계속 업데이트), 1MB 미만의 설치 용량.

## What's new (0.11.1)

• QR 코드 스캔, 기기 내에서 처리. ScamShield가 이제 페이지 이미지에 있는 QR 코드를 해석해, 휴대폰으로 스캔하기 전에 어디로 연결되는지 확인합니다. "퀴싱"(QR 코드 피싱) 이메일에 대한 기기 내 대응책입니다. 팝업에서 원하는 페이지를 스캔하거나 자동 스캔을 켜 두면 됩니다. QR 코드에 관한 어떤 정보도 기기 밖으로 나가지 않습니다.

• 카드 정보 도용 방지 기능이 이제 자동 제출 양식도 포함합니다. 사용자가 직접 제출한 양식뿐 아니라, 페이지가 스스로 다른 도메인으로 제출하는 로그인이나 카드 양식도 이제 같은 교차 사이트 경고를 발생시킵니다.

• 위협 피드의 오탐 방지 허용 목록을 넓혀, 더 많은 지역 은행, 정부, 마켓플레이스 도메인이 오염된 소스로 인해 잘못 차단되는 일이 없도록 했습니다.

• Gmail 등의 사이트에서 나타나는 콘솔 경고를 줄였습니다.

새로운 권한은 없습니다. 0.3.1 버전 이후 모든 버전과 마찬가지로 storage, declarativeNetRequest, alarms, http/https 접근 권한만 사용합니다.
