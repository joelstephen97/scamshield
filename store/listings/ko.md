## Name

ScamShield — 사기 및 피싱 방지

## Short description

기기에서 사기와 피싱을 방지: 경고 표시, 브랜드 위장 감지, 메시지 확인. 데이터는 기기를 벗어나지 않습니다.

## Full description

ScamShield는 사기나 피싱 페이지에 속기 전에 경고합니다 — 모두 기기에서 이루어집니다. 주소창만
보는 것이 아니라 페이지의 문구, 레이아웃, 로그인 양식까지 분석하며, 페이지가 브랜드의 아이콘이나
로고를 잘못된 도메인에서 사용하고 있는지 인식하므로, URL만 확인하는 검사로는 놓칠 만한 정교한
위장도 잡아냅니다. 의심스러운 WhatsApp, SMS, 이메일을 받으셨나요? 팝업에 붙여넣으면 즉시
비공개로 판정 결과를 받을 수 있습니다.

한 번의 클릭으로 안전하게 돌아갈 수 있습니다: 위험 경고에서는 "이 페이지 나가기", 브랜드 사칭
페이지에서는 "진짜 사이트로 이동". ScamShield의 판단이 틀렸다면 "이 사이트 신뢰"를 1시간,
내일까지, 또는 항상으로 설정할 수 있고, "오류 신고"도 한 번의 탭으로 가능합니다.

설계 단계부터 프라이버시를 고려했습니다: 사용자가 탐색하거나 입력하거나 확인한 내용은 절대
기기 밖으로 나가지 않습니다. 유일한 네트워크 활동은 공개 위협 목록 파일을 다운로드하는 것과,
(옵트인한 경우에만) 표시된 페이지에 대해 익명화된 호스트 이름과 위험 신호를 전송하는 것뿐입니다.
설정 페이지에서 기기 밖으로 나가는 내용을 정확히 확인할 수 있어, 직접 무텔레메트리를 검증할 수
있습니다.

메뉴, 경고, 설정의 완전한 번역을 포함해 20개 언어를 지원합니다 — 스토어 등록 정보만 번역된 것이
아닙니다.

주요 기능:
• 실시간 피싱 및 사기 경고와 이해하기 쉬운 이유 설명
• 페이지 분석: 기기 내 모델이 페이지 자체(문구, 레이아웃, 로그인 양식)를 분석하여 알려진 악성
  URL뿐 아니라 새로 생긴 피싱 페이지까지 잡아냅니다
• 브랜드 위장 탐지: 아이콘과 로고를 64개 브랜드 목록(그중 49개는 아이콘 해시 포함)과
  대조합니다. UAE 은행, 통신사, 정부 서비스(Emirates NBD, ADCB, FAB, Mashreq, e&, du, Noon,
  UAE PASS, MOHRE, Dubai Police 등)를 포함하며, IDN 동형이의 도메인(라틴 문자와 비슷한 외국
  문자를 사용하는 도메인)도 탐지합니다
• 사기 메시지 검사기: SMS/WhatsApp/이메일 텍스트를 붙여넣으면 즉시 완전 비공개로 판정 결과를
  받을 수 있습니다
• 비밀번호를 다른 사이트로 전송하는 가짜 로그인 양식을 탐지합니다(Google/Microsoft/Okta를
  통한 SSO 로그인은 안전한 것으로 인식됩니다)
• 프라이버시 팩: 제출 버튼을 누르기 전에 이메일/전화번호가 트래커로 전송될 때 경고하고,
  핑거프린팅 스크립트를 식별하며, "계속하려면 허용 클릭" 알림 권한 유도를 표시합니다
• 쇼핑 점검: 가짜 카운트다운, 가짜 "2개 남음" 압박, 핫링크된 신뢰 배지, 플랫폼 외부 결제 요청,
  연락처 정보 누락을 팝업 쇼핑 카드에 표시합니다
• Google/Bing/DuckDuckGo에서의 광고 결과 점검 — 표시된 사이트와 다른 곳으로 이동하는 광고에
  플래그를 표시합니다
• 거의 확실한 사기(ClickFix 가짜 CAPTCHA 클립보드 공격, 가짜 브라우저 업데이트 알림, 배송비
  피싱, 기술 지원 공포 유도 페이지)에 대한 전체 화면 경고 — 강제 일시정지와 진짜/가짜 도메인
  비교를 제공하며, 오탐이 거의 없는 탐지에만 사용됩니다
• 엄격 모드: 토글 하나로 "의심스러운" 페이지도 더 쉬운 문구와 함께 전체 화면으로 차단합니다.
  인터넷에 익숙하지 않은 가족에게 유용합니다
• 원클릭 구조: 브랜드 사칭 페이지에서는 "진짜 사이트로 이동", 위험 경고에서는 "이 페이지
  나가기"
• 사이트를 1시간, 내일까지, 또는 항상 신뢰하도록 설정할 수 있고, 오류도 한 번의 탭으로 신고할
  수 있습니다
• 알려진 사기 도메인 차단 — 오픈소스 피드(OpenPhish + URLhaus, 오탐을 엄격히 필터링)에서 매일
  갱신됩니다
• 암호화폐 지갑 보호: 위험한 승인 및 블라인드 서명(EIP-7702 계정 위임, EIP-6963 다중 지갑
  지원 포함) 전에 경고하고, 복구 문구 도난을 차단합니다
• 클립보드 탈취 보호: 사이트가 클립보드에 명령을 복사할 때 경고합니다
• 가짜 경품/이벤트 사기 콘텐츠를 숨깁니다
• 설정 내보내기/가져오기 및 선택적 기기 간 동기화(브라우저 자체 동기화 사용 — ScamShield
  계정이나 서버는 여전히 없음)
• 기기에만 저장되는 보호 기록 및 통계; 다크 모드
• 선택적 커뮤니티 신고, 기본값은 꺼짐 — URL이나 페이지 텍스트는 절대 포함하지 않음
• 더 가볍고 빠름: 압축 해제 시 약 0.6MB, 무거운 런타임 없음
• 100% 기기 내 분석 — 추적 없음, 데이터 수집 없음

## What's new (0.6.0)

'진짜 문제만' 해결하는 릴리스 — 모든 신규 기능은 검증된 실제 사기나 프라이버시 패턴을
대상으로 하며, 어떤 것도 권한을 추가하지 않습니다.

- 피싱 양식이 눈에 보이지 않게 숨어 있던 iframe 내부도 이제 스캔합니다.
- 거의 확실한 사기(ClickFix 가짜 CAPTCHA 클립보드 공격, 가짜 브라우저 업데이트 알림, 배송비
  피싱(DHL/FedEx/Aramex/Royal Mail/Evri/Emirates Post/DPD), 기술 지원 공포 유도 페이지)를
  위한 새로운 전체 화면 경고 등급을 추가했습니다 — 강제 일시정지와 진짜/가짜 도메인 비교를
  제공하며, 오탐이 거의 없는 탐지에만 사용됩니다.
- 새로운 프라이버시 팩: 폼 유출 경고(제출 버튼을 누르기 전에 이메일/전화번호가 평문 또는
  해시 처리되어 트래커로 전송), 핑거프린팅 감지, 알림 권한 유도 경고 — 모두 기기에서
  처리됩니다.
- 새로운 쇼핑 점검: 가짜 카운트다운, 가짜 "2개 남음" 압박, 핫링크된 신뢰 배지, 플랫폼 외부
  결제 요청, 연락처 정보 누락에 더해 Google/Bing/DuckDuckGo 광고 결과 점검을 추가했습니다.
- 엄격 모드: 토글 하나로 "의심스러운" 페이지도 더 쉬운 문구와 함께 전체 화면으로 차단하여,
  인터넷에 익숙하지 않은 가족을 안전하게 지킬 수 있도록 돕습니다.
- 설정 내보내기/가져오기 및 선택적 기기 간 동기화(브라우저 자체 동기화 사용 — ScamShield
  계정이나 서버는 여전히 없음).
- IDN 동형이의 탐지 및 지갑 탈취 방지 기능 강화(EIP-6963 다중 지갑 지원, EIP-7702 계정 위임
  탐지).
- 메뉴, 경고, 설정의 완전한 번역을 포함한 20개 언어 지원 — 스토어 등록 정보만이 아닙니다.

새로운 권한 추가는 없습니다. 0.3.1과 동일하게 `storage`, `declarativeNetRequest`, `alarms`
및 http/https 접근만 사용합니다.
