## Name

诈骗与钓鱼拦截器：ScamShield

## Short description

拦截诈骗网站、钓鱼页面和虚假商店。100% 本地处理——您的浏览内容永远不会离开您的电脑。

## Full description

没有服务器。ScamShield 会读取您正在浏览的页面、您粘贴的消息，以及您正在结账的
商店——完全在您的浏览器内部完成——绝不会把您浏览、输入或粘贴的内容发送到
其他任何地方。

**为什么选择 ScamShield**

大多数反诈骗扩展都会"回传数据"：它们把您访问的页面或其哈希值发送到某家
公司的服务器，再获得一个判定结果。ScamShield 不这样做，因为它不需要——原本要在
云端运行的检测，改为在本地运行。这意味着无需账户，不会因服务器故障而让您
失去防护，也不会有任何关于您浏览行为的信息可能泄露、被传票要求提供，或日
后被悄悄出售。它是免费的，没有付费档位，没有试用期，也没有"升级以解锁实时
防护"——整个产品就是免费产品。

**它会拦截什么**

- **仿冒银行与品牌的登录页面** — ScamShield 会用哈希比对页面的图标和 logo，
  与包含 64 个品牌的表格进行匹配（包括阿联酋的银行、电信运营商和政府服务，
  以及 PayPal、Microsoft、Google 等），并能检测使用相似外文字符拼写品牌
  名称的 IDN 同形异义域名。即使地址本身看起来眼熟，用错误域名承载正确 logo
  的假登录页也会被识别出来。
- **虚假商店** — 虚假倒计时、虚假的"仅剩 2 件"紧迫感、盗链的信任徽章、
  平台外支付要求以及缺失的联系方式，都会在结账前显示在弹出的购物提示卡中。
- **加密钱包盗取（drainer）** — 在您批准高风险授权和盲签名之前发出警告，
  包括 EIP-7702 账户委托和 EIP-6963 多钱包请求，并直接拦截助记词窃取
  尝试。
- **技术支持诈骗** — 针对"您的电脑已感染病毒，请立即拨打此号码"类页面
  提供全屏拦截，并提供一键脱离方式，先解除页面的锁屏和后退按钮陷阱。
- **ClickFix 与剪贴板攻击** — 2025 年增长最快的恶意软件手法：一个假冒的
  "验证您是人类"验证码，诱使您在 Windows"运行"框中粘贴命令。ScamShield 会
  覆盖恶意的剪贴板内容，并在其被执行之前将页面全屏拦截。
- **信息泄露表单** — 在网站于您点击提交*之前*就把您输入的邮箱或电话发送
  给追踪器的那一刻发出警告，并单独指出指纹追踪脚本和"点击允许以继续"的
  通知权限陷阱。

**工作原理**

1. ScamShield 会在您打开页面的瞬间，在您的设备上读取页面本身——其文字内容、
   布局、登录表单和图标——或您为核查诈骗消息而粘贴到弹窗中的消息。
2. 设备端模型和一套规则会对发现的内容打分。单一的弱信号绝不会产生比安静
   的"可疑"提示更强的结果；而"危险"判定需要多个独立信号一致，因此正常
   页面很少被误判。
3. 您获得的是通俗易懂的原因说明，而不只是一条红色横幅，并附带一键解决
   方案：在危险警告中点击*离开此页面*，在品牌仿冒页面中点击*前往真正的
   网站*——或者，如果 ScamShield 判断有误，可以将该网站的警告暂停一小时、
   一天或永久暂停。

**统计与可解释性**

每条警告都可以展开为*为什么是这个判定？*面板，列出背后的确切原因——例如
错误域名上的品牌图标、形似的域名、发送到外部主机的密码字段——而不是一个
无法解释的分数。设置中的统计标签页会显示已检查的页面数、已阻止的威胁和
隐私发现，并配有每日活动图表，可在最近 7 天、最近 30 天或安装以来的总计
之间切换。每一个数字都在您的设备上计算和存储；没有任何数字会被发送到
任何地方。

**隐私：ScamShield 会做什么，不会做什么**

ScamShield 请求访问您所浏览页面的权限，是因为设备端分析正是通过这种方式来
真正读取内容——文字、布局、登录表单和图标——检查在本地、在您的浏览器中
完成，而不是在某处的服务器上。默认情况下唯一离开您设备的是一次普通的
文件下载：已知诈骗域名的公开威胁列表，定期从 ScamShield 的开源数据源获取，
以便在安装后立即以及离线时也能正常拦截。这次下载不会附带任何关于您本人
或您具体浏览内容的信息。可选且默认关闭的社区举报功能，可以为被标记为
危险的页面发送经过匿名化处理的主机名和一个数值风险信号——绝不会发送
URL、页面文字或您输入的任何内容——且仅在您自己开启该功能时才会发送。
设置 → 关于会准确显示已经离开您设备的内容，让您可以亲自验证零遥测，
而不必只是相信我们的说法。

**常见问题**

**ScamShield 与 Guardio、Malwarebytes 或 Norton 有什么不同？**

那些扩展通过将信息发送到各自的服务器来检查您访问的页面：Guardio 和
Bitdefender TrafficLight 在云端扫描页面，Norton Safe Web 运行一项
"远程 URL 信誉服务"，并且根据其自身披露，会收集您的个人身份信息、位置
和网页浏览历史，而 Avast Online Security 会将您访问的 URL 连同设备 ID
和设备信息一起发送到其服务器。ScamShield 没有服务器。每一次检查——读取页面、
比对品牌图标、扫描粘贴的消息——都在您的设备上运行，您浏览、输入或检查的
任何内容都不会被发送到任何地方。Guardio 自己的商店介绍也表明，其免费
档位仅限于网站警报；实时拦截、下载防护和数据泄露监控都是付费功能
（每月 9.99–34.99 美元）。ScamShield 的完整功能集——实时拦截、虚假商店检测、
加密钱包盗取防护、技术支持诈骗拦截、剪贴板/ClickFix 防护、统计仪表盘，
以及每条警告都附带的通俗原因说明——全部免费，没有付费档位。

**ScamShield 真的完全免费吗？有什么套路吗？**

是的，完全没有套路：没有付费档位，没有试用期，也没有"升级以解锁实时
防护"。ScamShield 不运营需要向您收费的服务器，因此没有什么可以额外推销的
——整个产品就是免费产品。这与该品类中大多数产品的做法不同：一些竞品会
赠送有限的免费档位，并为真正的防护按月收费（Guardio 的免费档位仅提供
警报，完整拦截功能每月收费 9.99–34.99 美元），另一些则是免费扩展，但会
向您交叉推销付费安全套件。ScamShield 以另一种方式维持运营——保持体积小巧、
运行在设备本地，并足够有用以让您愿意继续安装，再加上可选的捐赠。如果
您想支持开发，扩展内有一个链接，但绝不会设置付费门槛。

**同时包含**

用具体数字说话，而非形容词：支持 **20 种语言**，包含菜单、警告和设置的
完整翻译（而不仅仅是翻译过的商店页面）；约 **630 项自动化测试**；一份
包含数千个诈骗域名、并持续从开源数据源更新的拦截列表；以及不到 1MB 的
安装体积——压缩后约 450KB，没有沉重的运行时。
