## Name

詐欺・フィッシング対策: ScamShield

## Short description

詐欺サイト、フィッシング、偽ショップをブロック。完全オンデバイスで、閲覧履歴は一切外部に送信されません。

## Full description

ScamShieldは、詐欺やフィッシングのページに騙される前に警告します。すべてのチェックはブラウザの中だけで行われます。サーバーはありません。閲覧、入力、貼り付けた内容が外部に送信されることはありません。

ScamShieldを選ぶ理由

多くの詐欺ブロッカーは、あなたが訪れたページを企業のサーバーに送信し、判定結果を待ちます。ScamShieldは同じ検出処理をお使いの端末上で行います。そのため、アカウント登録は不要で、サーバー障害で保護が効かなくなることもなく、あとで漏洩したり売買されたりする閲覧記録も残りません。

ScamShieldは無料で、有料プランも、お試し期間も、「アップグレードしてリアルタイム保護を解除」といった仕組みもありません。製品そのものが無料版です。

ブロックする内容

• 偽の銀行・ブランドログインページ。ScamShieldはページのアイコンとロゴを、PayPal、Microsoft、Googleを含む主要ブランド49件の指紋と照合し、さらにアドレスを300を超えるブランド名の一覧と突き合わせて、地域の銀行、通信、行政サービスも対象に、外国文字でブランド名を模したなりすましドメインを見つけ出します。正しいロゴが間違ったドメインに使われている偽ログインは、アドレスが見慣れないものであっても検出されます。

• 偽ショップ。偽のカウントダウンタイマー、「残り2点」といった煽り文句、模倣された信頼バッジ、プラットフォーム外での支払い要求、連絡先情報の欠落などを、チェックアウト前にショッピングカードで表示します。

• 暗号資産ウォレットの窃取攻撃。アカウント委任やマルチウォレットへのリクエストを含む、危険な承認やブラインド署名の前に警告し、リカバリーフレーズを盗もうとする試みをブロックします。

• サポート詐欺。「PCがウイルスに感染しています、こちらに電話してください」といったページを全画面でブロックします。ページの画面ロックや戻るボタンの罠を先に解除してから、ワンクリックで退出できます。

• ClickFixとクリップボード攻撃。「人間であることを確認してください」という偽の確認画面で、Windowsの「ファイル名を指定して実行」にコマンドを貼り付けさせようとする手口です。ScamShieldは悪意のあるクリップボードの内容を置き換え、実行される前にページをブロックします。

• 情報漏洩フォーム。入力したメールアドレスや電話番号がトラッカーに送信された瞬間、送信ボタンを押す前に警告します。フィンガープリンティングスクリプトや「続けるには許可をクリック」という通知の罠も明示します。

• 危険な検索結果。Google、Bing、DuckDuckGoでは、既知の危険ドメインやブランドへのなりすましに近い結果に小さな赤またはオレンジのドットが表示され、クリックする前にリスクがわかります。

• QRコード。ページの画像内に表示されたQRコードを解析し、スマートフォンでスキャンする前にリンク先を確認します。

仕組み

1. ページを開いた瞬間に、ScamShieldがお使いの端末上でそのページの文面、レイアウト、ログインフォーム、アイコンを読み取ります。ポップアップに貼り付けたメッセージを読み取ることもできます。

2. 端末上で動作するモデルとルールが、検出結果をスコア化します。弱いシグナル1つだけでは、目立たない「不審」の表示にとどまります。「危険」の判定には複数の独立したシグナルが一致する必要があるため、正規のページが誤って警告されることはほとんどありません。

3. 赤いバナーが出るだけでなく、わかりやすい言葉で理由が示され、ワンクリックで対処できます。危険な警告には「このページを離れる」、なりすましページには「本物のサイトへ移動」というボタンがあります。ScamShieldの判定が誤っていた場合は、そのサイトの警告を1時間、1日、または常に一時停止できます。

統計と説明

すべての警告には「この判定の理由」パネルがあり、間違ったドメインに使われたブランドアイコン、なりすましアドレス、別のサイトに送信されるパスワード欄など、具体的な理由が一覧表示されます。設定内の統計タブでは、チェックしたページ数、防いだ脅威、プライバシーに関する検出結果を、過去7日間、過去30日間、またはインストール以降の累計として日別グラフで確認できます。数値はすべてお使いの端末上で計算・保存されます。

プライバシー

ScamShieldが閲覧ページへのアクセス許可を求めるのは、端末上での解析がその方法でページを読み取るためです。チェックはブラウザ内でローカルに行われます。

デフォルトで端末の外に出る唯一のものは、単純なファイルのダウンロードです。既知の詐欺ドメインの公開リストをScamShieldのオープンソースフィードから取得することで、インストール直後やオフライン時でもブロック機能が働きます。このダウンロードに、あなたやあなたの閲覧に関する情報が含まれることはありません。

デフォルトでオフになっているコミュニティレポート機能を有効にすると、「危険」と判定されたページについて、匿名化されたホスト名と数値のリスク信号を送信できます。URLやページの内容、入力した情報が送信されることは一切なく、自分で有効にした場合のみ機能します。設定内の「概要」で、端末から送信された内容を正確に確認できます。

よくある質問

ScamShieldは他の詐欺ブロッカーやAI詐欺チェッカーと何が違いますか?

他の多くの製品は、訪れたアドレス、端末ID、チャットボットに貼り付けたメッセージなどの情報を自社サーバーに送信してチェックします。ScamShieldにはサーバーがありません。ページの読み取り、ブランドアイコンの照合、貼り付けたメッセージのスキャン、QRコードの解析はすべてお使いの端末上で行われます。他製品との詳しい比較は、プロジェクトのGitHubリポジトリ内のdocs/comparison.mdをご覧ください。

ScamShieldは本当に無料ですか? 何か裏があるのでは?

はい、本当に無料で、裏はありません。ScamShieldは課金対象となるサーバーを運用していないため、追加課金するものがありません。多くの競合製品は制限付きの無料プランを提供し、本当の保護には月額料金を課したり、有料のセキュリティスイートへ誘導したりします。ScamShieldは小さく、端末上で完結し、それでいてインストールし続けたくなるだけの実用性を保っています。開発を支援したい場合は、拡張機能内に寄付リンクがありますが、有料の壁は一切ありません。

その他の機能

• 詐欺メッセージチェッカー: SMS、WhatsApp、メールの文面を貼り付けるだけで、完全にプライベートな即時判定が得られます。

• 検索ページでのスポンサー結果チェック: 表示先と実際のリンク先が異なる広告にフラグを立てます。

• 厳格モード: トグル1つで「不審」なページも全画面でブロックし、よりシンプルな言葉で表示します。ITに詳しくないご家族にも安心です。

• 表示言語: ポップアップまたは設定から、ブラウザの言語設定とは無関係に20言語すべてから選べます。

• 設定のエクスポート/インポートと、お使いのブラウザ自体の同期機能を使った任意のデバイス間同期に対応しています。ScamShieldのアカウントやサーバーは引き続き不要です。

• ダークモード、保護履歴、ワンクリックの復旧リンク、偽の懸賞・プレゼント企画の非表示機能。

形容詞ではなく具体的な数字で: メニュー、警告、設定まで完全対応した20言語、約900件の自動テスト、確認済みの詐欺ドメイン425,000件超に加え100万件規模のウォッチリストからなるブロックリスト(オープンソースフィードから継続的に更新)、そして1MB未満のインストールサイズ。

## What's new (0.13.0)

• 1時間ごとの緊急リスト。毎日再構築される脅威リストに加えて、ScamShieldは過去48時間に報告されたサイトの小さなリストを1時間に1回ダウンロードするようになりました。今朝現れたばかりの詐欺サイトも、報告からおよそ1時間後には読み込まれる前に停止されます。全員に同じ公開ファイルで、通常のファイルダウンロードと同じように取得します。アカウントは不要で、あなたや閲覧内容に関する情報はどこにも送られません。

• どの警告からでも、このサイトを信頼できます。バナー、全画面警告、ブロックページのいずれにも「詐欺ではありませんか？このサイトを信頼する」がワンクリックで用意され、誤って押しても取り消せます。警告から信頼したサイトは設定でその旨が表示されるので、それぞれがどのようにリストに入ったか常に確認できます。

• 対応ブランドを拡大。偽装チェックが300を超えるブランドに対応し、銀行・配送・ゲームの偽ログインページをロゴだけでなく名称からも検出できるようになりました。

• 本物のサイトでの誤検知を削減。国別の形式のアドレスを使う本物の銀行、行政、企業のサイト（たとえば銀行自身の .bank.in ドメインなど）には、もう警告バナーが表示されません。

• 主張ではなく実測。最新のフィッシングページ 134 件のうち、ScamShield 0.13.0 は読み込み前に 56 % を遮断し、合計 69 % を阻止しました。ScamShield のサーバーへの通信は一切ありません。方法は docs/benchmark.md に記載しています。

新しい権限の追加はありません。0.3.1以降のすべてのバージョンと同様に、storage、declarativeNetRequest、alarms、http/httpsアクセスのみです。
