## Name

ScamShield — 詐欺・フィッシング対策

## Short description

端末上で詐欺やフィッシングから保護：警告表示、ブランドの偽装検出、メッセージ確認。データは端末の外に出ません。

## Full description

ScamShieldは、詐欺やフィッシングページに騙される前に警告します — すべて端末上で完結します。
アドレスバーだけでなく、ページの文章・レイアウト・ログインフォームまで解析し、ブランドのアイコンや
ロゴが誤ったドメインで使われていることを認識するため、URLだけをチェックするツールでは見逃して
しまうような巧妙な偽装も検出します。不審なWhatsApp、SMS、メールを受け取ったら？ポップアップに
貼り付ければ、瞬時にプライベートな判定結果が得られます。

ワンクリックで安全な状態に戻れます：危険な警告では「このページを離れる」、ブランド偽装ページでは
「本物のサイトへ移動」。ScamShieldの判定が間違っていた場合は、「このサイトを信頼」を1時間、明日
まで、または常にに設定でき、「誤りを報告」もワンタップで行えます。

設計段階からプライベート：閲覧、入力、確認した内容が端末の外に出ることは一切ありません。唯一の
通信は公開の脅威フィードファイルのダウンロードと、（オプトインした場合のみ）フラグが立てられた
ページの匿名化されたホスト名とリスク信号の送信です。設定ページでは端末の外に出る内容を正確に
確認でき、テレメトリがゼロであることをご自身で検証できます。

メニュー、警告、設定を含む完全な翻訳で20言語に対応しています — ストア掲載情報だけの翻訳では
ありません。

主な機能：
• リアルタイムのフィッシング・詐欺警告と、わかりやすい言葉での理由説明
• ページ解析：端末上のモデルがページ自体（文章・レイアウト・ログインフォーム）を解析し、既知の
  悪質URLだけでなく、生まれたばかりのフィッシングページも検出します
• ブランド偽装検出：アイコンやロゴを64ブランドのテーブル（うち49ブランドはアイコンハッシュ付き）
  と照合します。UAEの銀行、通信会社、政府サービス（Emirates NBD、ADCB、FAB、Mashreq、e&、du、
  Noon、UAE PASS、MOHRE、Dubai Policeなど）を含み、さらにIDNホモグラフドメイン（ラテン文字に
  似た外国文字を使ったドメイン）も検出します
• 詐欺メッセージチェッカー：SMS／WhatsApp／メールの文章を貼り付けるだけで、瞬時に完全プライベート
  な判定結果が得られます
• パスワードを別のサイトに送信する偽ログインフォームを検出します（Google／Microsoft／Oktaによる
  シングルサインオンログインは安全と認識されます）
• プライバシーパック：送信ボタンを押す前にメール／電話番号がトラッカーに送信された場合に警告し、
  フィンガープリントを取得するスクリプトを特定し、「続けるには許可をクリック」という通知許可
  トラップにフラグを立てます
• ショッピングチェック：偽のカウントダウン、偽の「残り2点」プレッシャー、ホットリンクされた信頼
  バッジ、プラットフォーム外決済の要求、連絡先情報の欠如をポップアップのショッピングカードで
  表示します
• Google／Bing／DuckDuckGoでの広告結果チェック — 表示されているサイトとは異なる場所に遷移する
  広告にフラグを立てます
• ほぼ確実な詐欺（ClickFixの偽CAPTCHAクリップボード攻撃、偽ブラウザ更新プロンプト、配送料
  フィッシング、サポート詐欺の脅迫ページ）に対する全画面警告。強制的な一時停止と本物・偽物ドメイン
  の比較を表示し、誤検知がほぼゼロの検出にのみ使用されます
• 厳格モード：ワンタップで「不審」なページも全画面でブロックし、よりシンプルな文言を表示します。
  ITに詳しくない家族に最適です
• ワンクリックで脱出：ブランド偽装ページでは「本物のサイトへ移動」、危険な警告では「このページを
  離れる」
• サイトを1時間、明日まで、または常に信頼するよう設定でき、誤りもワンタップで報告できます
• 既知の詐欺ドメインをブロック — オープンソースフィード（OpenPhish + URLhaus、誤検知を厳しく
  フィルタリング済み）から毎日更新されます
• 暗号資産ウォレット保護：危険な承認やブラインド署名（EIP-7702アカウント委任、EIP-6963マルチ
  ウォレット対応を含む）の前に警告し、復元フレーズの窃取をブロックします
• クリップボード乗っ取り保護：サイトがコマンドをクリップボードにコピーした場合に警告します
• 偽の賞品・懸賞詐欺コンテンツを非表示にします
• 設定のエクスポート／インポートと、任意の端末間同期（ブラウザ自体の同期機能を使用 — ScamShield
  にアカウントやサーバーはありません）
• 保護履歴と統計を端末上にのみ保存；ダークモード対応
• 任意のコミュニティ報告機能（デフォルトではオフ） — URLやページ内容は含まれません
• より軽量・高速：展開後約0.6 MB、重いランタイムなし
• 100%端末上で解析 — 追跡もデータ収集も一切ありません

## What's new (0.6.0)

「本当に必要な機能だけ」のリリース — 新機能はすべて、実際に確認された詐欺やプライバシー侵害の
パターンに対応するものであり、権限の追加は一切ありません。

- フィッシングフォームが目に見えない形で隠れていたiframe内部もスキャンするようになりました。
- ほぼ確実な詐欺（ClickFixの偽CAPTCHAクリップボード攻撃、偽ブラウザ更新プロンプト、配送料
  フィッシング〔DHL／FedEx／Aramex／Royal Mail／Evri／Emirates Post／DPD〕、サポート詐欺の
  脅迫ページ）に対する新しい全画面警告レベルを追加。強制的な一時停止と本物・偽物ドメインの比較
  を表示し、誤検知がほぼゼロの検出にのみ使用されます。
- 新しいプライバシーパック：フォーム漏えい警告（送信前にメール／電話番号が平文またはハッシュ化
  されてトラッカーに送信される）、フィンガープリント検出、通知許可トラップ警告 — すべて端末上
  で処理されます。
- 新しいショッピングチェック：偽のカウントダウン、偽の「残り2点」プレッシャー、ホットリンク
  された信頼バッジ、プラットフォーム外決済の要求、連絡先情報の欠如に加え、Google／Bing／
  DuckDuckGoでの広告結果チェックを追加しました。
- 厳格モード：ワンタップで「不審」なページも全画面でブロックし、よりシンプルな文言を表示します。
  ITに詳しくない家族の安全を守るのに役立ちます。
- 設定のエクスポート／インポートと、任意の端末間同期（ブラウザ自体の同期機能を使用 — ScamShield
  にアカウントやサーバーはありません）。
- IDNホモグラフ検出と、ウォレットドレイナー対策の強化（EIP-6963マルチウォレット対応、EIP-7702
  アカウント委任検出）。
- メニュー、警告、設定を含む完全な翻訳で20言語に対応 — ストア掲載情報だけの翻訳ではありません。

新しい権限の追加はありません。0.3.1と同じく `storage`、`declarativeNetRequest`、`alarms`、
http／httpsアクセスのみです。
