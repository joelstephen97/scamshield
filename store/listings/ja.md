## Name

詐欺・フィッシング対策ブロッカー: ScamShield

## Short description

詐欺サイト、フィッシング、偽ショップをブロック。100%デバイス上で動作 — 閲覧内容がパソコンの外に出ることはありません。

## Full description

サーバーは存在しません。ScamShieldは、あなたが見ているページ、貼り付けたメッセージ、
支払いをしようとしているショップを — ブラウザの中だけで — 読み取り、閲覧・入力・
貼り付けた内容を他のどこにも送信しません。

**ScamShieldを選ぶ理由**

多くの詐欺対策拡張機能は「本国通信」を行います。訪れたページやそのハッシュ値を
企業のサーバーへ送り、判定を受け取ります。ScamShieldはそれをしません。必要ないから
です — クラウドで実行されるはずの検出処理を、代わりにローカルで実行します。つまり
アカウントは不要で、サーバー障害によって無防備になることもなく、あなたの閲覧に
関する情報が流出したり、召喚状で開示要求されたり、後で密かに販売されたりする
心配もありません。無料で、プレミアムプランも試用期間もなく、「リアルタイム保護の
ロック解除にはアップグレードが必要」ということもありません — 製品全体が無料の
製品です。

**ブロックする内容**

- **銀行・ブランドの偽ログイン** — ScamShieldはページのアイコンとロゴを64ブランドの
  テーブル（UAEの銀行、通信会社、政府サービスに加え、PayPal、Microsoft、Google
  なども含む）とハッシュ照合し、ブランド名を似た外国文字で綴るIDNホモグラフ
  ドメインも検出します。正しいロゴを間違ったドメインに使った偽ログインは、
  アドレス自体が見慣れたものに見えても検出されます。
- **偽ショップ** — 偽のカウントダウンタイマー、偽の「残り2点」プレッシャー、
  ホットリンクされた信頼バッジ、プラットフォーム外決済の要求、連絡先情報の欠如
  を、決済前にポップアップのショッピングカードで表示します。
- **暗号資産ウォレットドレイナー** — EIP-7702のアカウント委任やEIP-6963の
  マルチウォレット要求を含む、リスクの高い承認やブラインド署名の前に警告し、
  リカバリーフレーズの窃取試行は完全にブロックします。
- **テクニカルサポート詐欺** — 「PCが感染しています、今すぐこの番号に電話して
  ください」というページを全画面でブロックし、まずページの画面ロックと戻る
  ボタンの罠を無効化するワンクリックの脱出手段を提供します。
- **ClickFixとクリップボード攻撃** — 2025年に最も急増しているマルウェアの手口：
  偽の「人間であることを確認」CAPTCHAが、Windowsの「ファイル名を指定して実行」
  にコマンドを貼り付けるよう仕向けます。ScamShieldは悪意あるクリップボードの内容を
  上書きし、実行される前にページを全画面でブロックします。
- **情報漏えいフォーム** — サイトが入力したメールアドレスや電話番号を送信ボタン
  を押す*前に*トラッカーへ送信した瞬間に警告し、フィンガープリンティング
  スクリプトや「続けるには許可をクリック」という通知権限の罠も個別に指摘します。

**仕組み**

1. ScamShieldはページを開いた瞬間に、その文言・レイアウト・ログインフォーム・
   アイコンをデバイス上で読み取ります。詐欺メッセージのチェックのためポップ
   アップに貼り付けたメッセージも同様です。
2. デバイス上のモデルとルールセットが検出結果を評価します。単独の弱いシグナル
   だけでは静かな*疑わしい*という表示以上にはなりません。*危険*の判定には
   独立した複数のシグナルの一致が必要なため、正常なページが誤って警告される
   ことはめったにありません。
3. 単なる赤いバナーではなく、平易な言葉で理由が示され、ワンクリックで対処
   できます：危険な警告では*このページを離れる*、ブランドなりすましページ
   では*本物のサイトへ移動*、ScamShieldの判定が誤っていた場合は、そのサイトの
   警告を1時間・1日・常に、のいずれかで一時停止できます。

**統計と説明可能性**

すべての警告は*なぜこの判定？*パネルに展開でき、説明のないスコアではなく、
間違ったドメイン上のブランドアイコン、なりすましドメイン、パスワード欄が
外部ホストへ送信していることなど、正確な理由を一覧表示します。設定内の
統計タブでは、確認したページ数、阻止した脅威、プライバシーに関する発見を
表示し、過去7日間・過去30日間・インストール以降の合計を切り替えられる
日次アクティビティのグラフも見られます。すべての数値はデバイス上で計算・
保存され、どこにも送信されることはありません。

**プライバシー：ScamShieldが行うこと・行わないこと**

ScamShieldが訪問したページへのアクセスを求めるのは、デバイス上の分析が実際に
文言・レイアウト・ログインフォーム・アイコンをそのように読み取るからです。
確認はサーバーではなく、あなたのブラウザ内でローカルに行われます。デフォルト
であなたのデバイスから外に出る唯一のものは、単純なファイルダウンロードです：
既知の詐欺ドメインの公開脅威リストで、インストール直後やオフライン時にも
ブロック機能が動作するよう、ScamShieldのオープンソースフィードから定期的に取得
されます。あなたやあなたの具体的な閲覧内容に関する情報がこのダウンロードに
付随することはありません。デフォルトで無効なオプションのコミュニティ報告
機能は、危険と判定されたページについて匿名化されたホスト名と数値のリスク
シグナルを送信できます — URL、ページのテキスト、入力した内容が送信される
ことは決してなく、あなた自身が有効にした場合のみです。設定 → このアプリに
ついてでは、デバイスから何が出ていったかを正確に示すため、私たちの言葉を
信じるのではなく、ゼロテレメトリーであることをご自身で確認できます。

**よくある質問**

**ScamShieldはGuardio、Malwarebytes、Nortonとどう違うのですか？**

これらの拡張機能は、訪問したページを確認する際に情報を自社サーバーへ送信
します。GuardioとBitdefender TrafficLightはクラウドでページをスキャンし、
Norton Safe Webは「リモートURLレピュテーションサービス」を運用し、自社の
開示によれば個人情報、位置情報、閲覧履歴を収集します。Avast Online Security
は訪問したURLをデバイスIDやデバイス情報とともに自社サーバーへ送信します。
ScamShieldにはサーバーがありません。ページを読む、ブランドアイコンを照合する、
貼り付けたメッセージをスキャンするといったすべての確認作業はデバイス上で
行われ、閲覧・入力・確認した内容がどこにも送信されることはありません。
Guardio自身の掲載情報でも、無料プランはウェブサイトの警告のみに限定されて
おり、リアルタイムブロック、ダウンロード保護、漏えい監視は有料機能です
（月額9.99～34.99ドル）。ScamShieldの全機能一式 — リアルタイムブロック、偽ショップ
検出、暗号資産ウォレットドレイナー対策、テクニカルサポート詐欺のブロック、
クリップボード/ClickFix保護、統計ダッシュボード、すべての警告における平易
な理由表示 — はプレミアムプランなしで無料です。

**ScamShieldは本当に無料ですか？何か裏がありますか？**

はい、裏は一切ありません：プレミアムプランなし、試用期間なし、「リアル
タイム保護のロック解除にはアップグレードが必要」もありません。ScamShieldは
課金対象となるサーバーを運用していないため、追加で売るものがありません
— 製品全体が無料の製品です。これはこのカテゴリーの多くとは異なるあり方
です：多くの競合製品は限定的な無料プランを提供し、本当の保護には月額料金
を課します（Guardioの無料プランは警告のみで、完全なブロックには月額
9.99～34.99ドルかかります）。他社は無料の拡張機能でありながら有料の
セキュリティスイートへクロスセルします。ScamShieldは別の方法で成り立っています
— 小規模で、デバイス上で動作し、あなたがインストールし続けたくなるほど
役立つことに加え、任意の寄付によってです。開発を支援したい場合は拡張機能
内にリンクがありますが、有料の壁は決してありません。

**その他の機能**

- 詐欺メッセージチェッカー — SMS/WhatsApp/メールのテキストを貼り付けると、
  即座に完全にプライベートな判定が得られます。
- Google/Bing/DuckDuckGoでのスポンサー結果チェック — 表示されているサイト
  とは異なる場所へ誘導する広告にフラグを立てます。
- 厳格モード — 技術にあまり詳しくない家族のために、1つの切り替えで
  「疑わしい」ページでもより簡単な言葉で全画面ブロックします。
- 言語の選択：ブラウザの言語に関係なく、ポップアップや設定から20言語すべて
  を選択できます。
- 設定のエクスポート/インポートと任意のデバイス間同期 — ブラウザ自体の
  同期機能を使用し、ScamShieldのアカウントやサーバーは依然として不要です。
- ダークモード、保護履歴、ワンクリックの救済リンク、偽の賞金/懸賞コンテンツ
  の非表示化。

形容詞ではなく具体的な数字で：メニュー・警告・設定の完全な翻訳を含む
**20言語**に対応（単に翻訳されたストア掲載情報だけではありません）。約
**630件**の自動テスト。オープンソースフィードから継続的に更新される、
数千件の詐欺ドメインを含むブロックリスト。そして1MB未満のインストール
サイズ — 圧縮時約450KBで、重いランタイムはありません。

## What's new (0.9.0)

- **大幅に拡大した脅威フィード。** ブロックリストは数千件のドメインから
  **42万5000件を超える確認済みの詐欺・フィッシングドメイン**へと拡大し、
  さらに信頼度がやや低い100万件以上のドメインを含むウォッチリストも追加
  されました——10以上のオープンソース脅威データベースから集約し、互いに
  突き合わせて検証し、世界で最も人気のあるサイトと照合してフィルタリング
  することで、誤検知を稀に抑えています。照合は引き続きすべて端末上で
  行われます。フィードはコンパクトなフィンガープリントとしてダウンロード
  され、ローカルで確認されるため、訪問したサイトがどこかに送信されること
  はありません。更新は数時間ごとに小さな差分として届きます。
- **ScamShieldがフィードに登録されたサイトをブロックすると、どの独立した情報源
  がそれを報告したかを表示するようになりました**——ブラックボックスの
  スコアではなく、検証可能な情報です。
- **より賢い偽装検出**：ブランドなりすましのチェックが、文字の入れ替え、
  似た文字、長いサブドメイン内に隠されたブランド名、入れ替えられたドメイン
  末尾を検出するようになりました。厳格な保護策により、本物のブランド
  サイトが誤ってフラグされることはありません。
- **新しい警告シグナル**：異常に深いサブドメインの連鎖、異常に長いアドレス
  部分、リンク短縮サービスの遷移先、詐欺の多いドメイン末尾、無料ホスティング
  プロバイダーが、ページの判定に注意情報として追加されるようになりました。

新しい権限はありません。0.3.1と全く同じく、`storage`、
`declarativeNetRequest`、`alarms`、http/httpsアクセスのみです。
