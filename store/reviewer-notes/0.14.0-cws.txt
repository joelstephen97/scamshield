No new permissions since 0.3.1 (still storage, declarativeNetRequest, alarms + http/https), no new hosts, no new network requests, nothing sent anywhere. 0.14.0 is a user-experience release: (1) the in-page warnings now remember the user's decisions locally — a per-site, per-warning-type mute ("Don't warn me on this site", stored in chrome.storage.local under the existing settings object, listed and reversible in the extension's Settings), a one-day pause when the warning bar is closed, and a one-hour pause when "Continue anyway" is chosen on the full-page warning; these reuse the existing pause/allowlist mechanism (the same declarativeNetRequest allow rules 0.12.0 introduced) and every such control only accepts a trusted user gesture on the extension's own UI; (2) a copy of a terminal command or a crypto address triggered by the user's own click on a site's copy button is now shown as an informational notice and is no longer counted as a blocked threat (the ClickFix fake-CAPTCHA detection is unchanged); (3) a false-positive fix so a page posting to its own subdomain is not reported as a third-party leak; (4) the warning bar, full-page warning, notices and dialogs are redesigned (same content-script injection, same single purpose, larger targets, visible focus, dark mode). The what's-new sentence and 26 new UI strings are translated into all 20 languages. CWS data-use form answers unchanged. Source: github.com/joelstephen97/scamshield, tag v0.14.0.
